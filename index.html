Data Security (सुरक्षा)

हम आपकी जानकारी सुरक्षित रखने के लिए निम्नलिखित उपाय करते हैं:

  • HTTPS/TLS Encryption: सभी Firebase communications encrypted हैं
  • Firebase Security Rules: Unauthorized access blocked है
  • Local Storage: Device का SQLite database — केवल आपका App access कर सकता है
  • Minimal Data: केवल जरूरी data एकत्र करते हैं
  • No Passwords: हम passwords store नहीं करते (Google OAuth use करते हैं)
⚠️ Important Note: Internet पर 100% security की guarantee नहीं दी जा सकती। अगर आपको security breach का संदेह हो तो तुरंत हमसे संपर्क करें।

Data Retention (कितने समय तक रखते हैं):

  • Account delete करने पर Firebase से data 30 दिनों में delete हो जाता है
  • App uninstall करने पर Local device data तुरंत delete हो जाता है
  • Forum posts — आपके account delete करने के बाद anonymized हो जाती हैं
